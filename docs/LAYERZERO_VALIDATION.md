## Static-analysis review

`tools/slither-reviewed.json` matches exact file/function/expression fingerprints. High or Medium
findings always fail the gate. No detector class is globally allowed.

- Four existing Wormhole timestamp findings retain their earlier rationale.
- Four equivalent LayerZero timestamp findings concern scheduled UI multipliers and snapshot age.
  They do not authorize minting, redemption or changes to raw balances. The source timestamp is
  authenticated, bounded by the clock-skew check, and cannot restart the lifetime on delivery.
  Boundary, future/stale snapshot, split/cancellation and raw-transfer tests cover these behaviors.
- The Low `reentrancy-events` finding in `LayerZeroEndpoint._send` identifies `MessageSent` after
  `endpoint.send`. The GUID and nonce are returned by that call, so the event follows publication.
  `_send` is reachable only from the `nonReentrant` deposit, redeem and metadata entry points.
  No asset-accounting callback bypasses that guard. Token callbacks and native-refund reentry have
  explicit regression tests; reverted execution rolls back publication and accounting together.
- Four Low `calls-loop` findings identify protocol reads/commits in `_commitVerifications`, from its
  two public entry paths. The array is supplied by the caller, addresses are pinned protocol contracts,
  and work can be split across transactions. Oversized batches revert only their own transaction;
  checkpointing advances a long verified backlog without executing blocked asset transfers.

A first analysis reported an ignored metadata `applySnapshot` return value. The implementation now
uses it in `MetadataReceived(guid, nonce, applied)`, making ignored older snapshots explicit. The
checkpoint implementation also initially triggered Medium findings. Moving the saved payload effect
before protocol interactions and routing saved execution through the guarded external entry point
resolved those findings without allowlisting them. The final analysis has no High/Medium findings.
Review of Low findings is internal, not an auditor's acceptance.
